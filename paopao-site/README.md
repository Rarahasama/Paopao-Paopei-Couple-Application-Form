# คำร้องขอเป็นแฟน — แบบฟอร์ม รก.๐๑

เว็บหน้าเดียว ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล คำตอบทั้งหมดอยู่ในเบราว์เซอร์ของคนที่เปิดเท่านั้น

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด (HTML + CSS + JS อยู่ในไฟล์เดียว) |
| `og.png` | รูปพรีวิวตอนส่งลิงก์ในไลน์ / เฟซบุ๊ก |
| `README.md` | ไฟล์นี้ ไม่มีผลกับหน้าเว็บ |

---

## วิธีขึ้น GitHub Pages (ไม่ต้องใช้ git ทำผ่านเว็บได้เลย)

1. เข้า github.com → กดปุ่ม **+** มุมขวาบน → **New repository**
2. ตั้งชื่อ repo เช่น `paopao` → เลือก **Public** → **Create repository**
   > ต้องเป็น Public เท่านั้น ถ้าใช้บัญชีฟรี Pages จะไม่ทำงานกับ repo แบบ Private
3. ในหน้า repo กด **uploading an existing file** → ลาก `index.html` กับ `og.png` เข้าไป → **Commit changes**
4. ไปที่แท็บ **Settings** → เมนูซ้าย **Pages**
5. หัวข้อ *Build and deployment* → Source เลือก **Deploy from a branch** → Branch เลือก **main** และโฟลเดอร์ **/ (root)** → **Save**
6. รอ 1–2 นาที แล้วรีเฟรชหน้า Pages จะได้ลิงก์หน้าตาแบบนี้

```
https://USERNAME.github.io/paopao/
```

## แก้ให้รูปพรีวิวขึ้นตอนส่งไลน์

เปิด `index.html` (กดชื่อไฟล์ใน GitHub แล้วกดรูปดินสอเพื่อแก้ได้เลย) หาบรรทัดนี้ประมาณบรรทัดที่ 12

```html
<meta property="og:url" content="https://USERNAME.github.io/REPO/">
<meta property="og:image" content="https://USERNAME.github.io/REPO/og.png">
```

เปลี่ยน `USERNAME` เป็นชื่อบัญชี GitHub และ `REPO` เป็นชื่อ repo ที่ตั้งไว้ แล้ว Commit

> ไลน์จะจำรูปพรีวิวของลิงก์ไว้ ถ้าเคยส่งลิงก์ไปก่อนแก้ ให้เติม `?v=2` ต่อท้ายลิงก์ตอนส่งใหม่ จะได้พรีวิวอันใหม่

## แก้ชื่อ / คำถาม

อยู่ในไฟล์ `index.html` ใต้บรรทัด `const CONFIG = {`

```js
const CONFIG = {
  ผู้ยื่นคำร้อง: "ตอเฮต (宝宝)",   // ชื่อเรา
  ชื่อเขา: "ฟรอยด์ (宝贝)",        // เว้นว่าง "" = ให้เขาพิมพ์ชื่อเอง
  ข้อความปิดท้าย: "...",           // ประโยคที่ขึ้นหลังกดยินยอม
};
```

คำถามอยู่ใน `const QUESTIONS = [` ถัดลงมา เพิ่มหรือลบข้อได้เลย เลขข้อกับหลอดความคืบหน้าคำนวณให้อัตโนมัติ

## ทดสอบก่อนส่ง

ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย ไม่ต้องอัปโหลดก่อน ทุกอย่างทำงานเหมือนตอนออนไลน์ ยกเว้นรูปพรีวิวลิงก์
