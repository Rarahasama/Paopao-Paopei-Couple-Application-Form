# แบบฟอร์มชุด รก. — เว็บสามหน้า

เว็บสแตติกล้วน ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล คำตอบทุกอย่างอยู่ในเครื่องของคนที่เปิดเท่านั้น

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | **หน้าแรก — สารบัญแฟ้ม** เลือกได้ว่าจะทำฟอร์มไหน |
| `love.html` | **ฟอร์ม รก.๐๑ — คำร้องขอเป็นแฟน** ๗ ข้อ จบด้วยตราอนุมัติ |
| `profile.html` | **ฟอร์ม รก.๐๒ — แบบบันทึกประวัติส่วนตัว** ๑๒ หมวด ๑๒๑ ข้อ |
| `og-home.png` | รูปพรีวิวลิงก์ของหน้าสารบัญ |
| `og.png` | รูปพรีวิวลิงก์ของหน้า รก.๐๑ |
| `og-profile.png` | รูปพรีวิวลิงก์ของหน้า รก.๐๒ |

ทั้งสามหน้าลิงก์ถึงกัน: สารบัญ → ฟอร์ม → กลับสารบัญ และหน้าสารบัญจะแสดงสถานะของแต่ละฟอร์มให้เอง
(รอดำเนินการ / อนุมัติแล้ว / กรอกแล้วกี่ข้อ) โดยอ่านจากเครื่องของผู้กรอก

**ต้องวางไฟล์ทั้งหมดไว้โฟลเดอร์เดียวกัน** ลิงก์ระหว่างหน้าถึงจะทำงาน

---

## วิธีขึ้น GitHub Pages (ทำผ่านเว็บ ไม่ต้องใช้ git)

1. github.com → ปุ่ม **+** มุมขวาบน → **New repository**
2. ตั้งชื่อ repo เช่น `paopao` → เลือก **Public** → **Create repository**
   > ต้อง Public เท่านั้น บัญชีฟรีใช้ Pages กับ repo แบบ Private ไม่ได้
3. กด **uploading an existing file** → ลากไฟล์ทั้ง ๔ ไฟล์เข้าไป → **Commit changes**
4. **Settings** → เมนูซ้าย **Pages**
5. *Build and deployment* → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
6. รอ ๑–๒ นาที จะได้ลิงก์

```
https://USERNAME.github.io/paopao/             ← หน้าสารบัญ (ส่งลิงก์นี้ให้เขา)
https://USERNAME.github.io/paopao/love.html    ← รก.๐๑ คำร้องขอเป็นแฟน
https://USERNAME.github.io/paopao/profile.html ← รก.๐๒ แฟ้มประวัติ
```

## แก้ให้รูปพรีวิวขึ้นตอนส่งไลน์

ทั้ง `index.html` และ `profile.html` มีบรรทัดนี้อยู่ช่วงบนของไฟล์

```html
<meta property="og:url" content="https://USERNAME.github.io/REPO/">
<meta property="og:image" content="https://USERNAME.github.io/REPO/og.png">
```

เปลี่ยน `USERNAME` เป็นชื่อบัญชี GitHub และ `REPO` เป็นชื่อ repo แล้ว Commit
ต้องแก้ทั้งสามไฟล์ โดยแต่ละไฟล์ชี้ไปคนละรูป

| ไฟล์ | og:url ลงท้ายด้วย | og:image |
|---|---|---|
| `index.html` | `/REPO/` | `og-home.png` |
| `love.html` | `/REPO/love.html` | `og.png` |
| `profile.html` | `/REPO/profile.html` | `og-profile.png` |

> ไลน์จำพรีวิวเดิมไว้ ถ้าเคยส่งลิงก์ไปก่อนแก้ ให้เติม `?v=2` ต่อท้ายตอนส่งใหม่

## แก้ชื่อ / คำถาม

ทั้งสองไฟล์มีบล็อก `const CONFIG = {` อยู่ต้น `<script>` แก้ชื่อได้ตรงนั้น

- `index.html` → รายการฟอร์มอยู่ใน `const FORMS = [` เพิ่มฟอร์มใหม่ได้ที่นี่
- `love.html` → คำถามอยู่ใน `const QUESTIONS = [` แบบตัวเลือก ๔ ข้อ
- `profile.html` → คำถามอยู่ใน `const SECTIONS = [` รูปแบบนี้

```js
{ t:"ชื่อหมวด", d:"คำอธิบายหมวด", f:[
  ["คำถาม", "t", "คำใบ้"],   // t = ช่องบรรทัดเดียว
  ["คำถาม", "a", "คำใบ้"],   // a = ช่องพิมพ์ยาว
]},
```

เพิ่มหรือลบหมวด/ข้อได้อิสระ เลขหมวด เลขข้อ และเปอร์เซ็นต์ความคืบหน้าคำนวณใหม่ให้เอง

## สิ่งที่ รก.๐๒ ทำได้

- **บันทึกร่างอัตโนมัติ** ปิดหน้าไปแล้วเปิดใหม่ กรอกต่อจากเดิมได้
- **คัดลอกทั้งหมด** เป็นข้อความ ส่งกลับทางไลน์ได้เลย
- **ดาวน์โหลดไฟล์** เป็น .txt
- **บันทึกเป็น PDF** ผ่านหน้าต่างสั่งพิมพ์ของเบราว์เซอร์ (จัดหน้าไว้ให้แล้ว)

## เพิ่มฟอร์มใหม่ในสารบัญ

เปิด `index.html` แล้วเพิ่มบล็อกใน `const FORMS = [`

```js
{
  code: "รก.๐๔",
  title: "ชื่อฟอร์ม",
  desc: "คำอธิบายสั้น ๆ",
  meta: ["๑๐ ข้อ", "ใช้เวลา ~๕ นาที"],
  href: "ชื่อไฟล์.html",
},
```

ใส่ `locked: true` แทน `href` ถ้าอยากโชว์แบบยังไม่เปิดให้กด

## ทดสอบก่อนส่ง

ดับเบิลคลิกไฟล์ HTML เปิดในเบราว์เซอร์ได้เลย ทำงานครบทุกอย่างเหมือนตอนออนไลน์ ยกเว้นรูปพรีวิวลิงก์
